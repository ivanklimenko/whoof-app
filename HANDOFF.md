# Whoof — передача разработчику, 29 сентября 2026

Это актуальная локальная версия прототипа со всеми правками из обсуждения.

## Запуск

Проверено на Node.js 26. Используется Vite 8; рекомендуется Node.js 22.12+ или 24+.

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 4178
```

Открыть http://localhost:4178/. Приложение сразу открывает главную без авторизации.

```sh
npm run build
npm run check:runtime
npx playwright test tests/annual-recap.spec.ts tests/vet-care.spec.ts
```

Два набора функциональных тестов используют установленный Google Chrome. Остальные тесты runtime используют Chromium из Playwright (`npx playwright install chromium`).

## Что передаётся

- Исходный React/TypeScript-проект, lockfile, настройки и тесты.
- Все используемые приложением изображения в `public/assets/`, включая фоны итогов года в `public/assets/recap/`.
- Референсы в `references/`, включая актуальный чёрный ошейник.
- Готовая сборка `dist/` (для пересборки используйте исходники).
- Правила и история дизайн-решений в `AGENTS.md`.

## Важные границы реализации

- Это frontend-прототип: показания, инсайты и сценарии используют локальные fixtures. Нет подключения к реальному устройству, врачу, клинике или backend.
- Ветеринарный сценарий использует отдельный фиксированный набор данных 04.08–28.09.2026. Инсайт сравнивает 08–14.09 с предыдущими 28 днями; он не пересчитывается от переключателя периода основных метрик.
- Причина, выбранные вложения, дата лечения и наблюдения хранятся в памяти до перезагрузки; сохраняются при переходах между вкладками.
- Существующая медкарта сохраняет файлы локально в IndexedDB; новые вложения обращения не записываются в медкарту автоматически. Ничего не отправляется без действия пользователя.
- Сохранение PDF, реальная запись к врачу, серверное хранение и синхронизация требуют отдельной реализации.
- Не менять защищённые файлы мобильного runtime без отдельной задачи. Основные изменения приложения: `src/Prototype.tsx`, `src/prototype.css`; текущая точка входа — `src/native-main.tsx`.
- Соблюдать текущий дизайн Whoof: типографику, градиентные иконки, светлые поверхности, скругления и чёрные основные кнопки.

Архив не содержит `node_modules`, временные отчёты тестов и системные файлы macOS. Для запуска внешние изображения из переписки не нужны.
